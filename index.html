A local-first system that turns language-model output into text answers, visual notes and flashcards.

Local LLMsMultimodal AIPython
Localinference focus

The problem

Cloud AI is powerful but depends on paid APIs and gives plain text. Learners need structured, visual material.

The solution

A chat adapter that connects model output to different formats: text, visual knowledge notes, flashcards and structured learning material.

Key decisions

  • Formerly named chat_model_final_adapter, renamed Local LLM
  • Prefers smaller models that run on modest hardware
  • Structured output so other parts of the app can use it

AI Website Publishing Agent

A pipeline that researches a topic, writes an SEO article, adds images and internal links, then publishes to WordPress after human approval.

Gemini 2.5 FlashWordPress REST APISQLite FTS5RAGSEO
11pipeline stages
2,000+words per article
Multi-sitedatabase design

The problem

Writing, optimizing and publishing quality content for several websites takes a lot of repeated manual work.

Pipeline (in order)

  1. Website and topic analysis
  2. Keyword research and competitor analysis
  3. AI content generation (about 2,000 to 2,500 words)
  4. Fact-checking
  5. AI image generation
  6. Internal link generation
  7. SEO optimization
  8. Quality assurance
  9. Human approval
  10. WordPress draft or publish

Knowledge layer

  • SQLite with FTS5 full-text search
  • Local embeddings and RAG
  • Multi-site architecture with logs and feature flags

Decisions

  • Gemini 2.5 Flash as main model to keep costs low
  • Claude considered for coding strength
  • Human approval step so nothing goes live unreviewed

Use case

Designed to support content for HeartRateTech.com and other sites.

X-Ray Analyzer

Upload an X-ray in the browser and see possible fracture regions marked with bounding boxes and confidence scores.

YOLOv8FlaskGoogle ColabPillowNumPyJavaScript
YOLOv8custom detector
Flaskinference API
Downloadannotated result

How it works (in order)

  1. Train a custom YOLOv8 model in Google Colab
  2. User uploads an X-ray in the web page
  3. Flask backend receives the image
  4. Model detects possible fracture regions
  5. Annotated image and confidence are returned
  6. User downloads the result

What I learned

Custom object detection, model inference, image processing with Pillow and NumPy, and wiring a trained model into a web interface.

Important note

This is an experimental learning project. It is not a medical device and does not replace a doctor.

Where it can improve

  • Test on held-out images and report precision and recall
  • Add more varied training data
